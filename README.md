# L'Affaire de Mecklenburgh Square

Une enquête de Sherlock Holmes à mener à deux, en une heure et demie environ, dans le Londres de novembre 1895.

**Jouer : https://theovoneuw-cell.github.io/affaire-mecklenburgh-square/**

- Tout se joue dans le navigateur, sur un ordinateur de préférence (grand écran, casque ou enceintes).
- Les règles sont expliquées sur la page d'accueil.
- La partie est sauvegardée dans le navigateur : on peut fermer l'onglet et reprendre plus tard sur le même ordinateur.

Les photographies d'époque, le plan de Londres de 1895 et les polices proviennent de fonds libres de droits ; le détail est dans [CREDITS.md](CREDITS.md).
